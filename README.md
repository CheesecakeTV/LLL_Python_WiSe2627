
# Python-Kurs LLL WiSe 26-27
Offizielles Repository für den LLL Python-Kurs im WISE 26-27.

# Bevor es losgeht
Installiere dir bitte Python und eine IDE.
Eine Anleitung dazu findest du [hier](https://github.com/CheesecakeTV/LLL_Python_WiSe2627/blob/main/Installationsanleitung.md) im GitHub Repository.

Der gesamte Kurs wird in der IDE PyCharm vorgestellt.
Du darfst gerne eine andere IDE nutzen, aber falls damit Probleme auftreten, bist du auf dich allein gestellt.
In der Vergangenheit hat sich gezeigt, dass VS Code deutlich weniger einsteigerfreundlich ist als PyCharm.

# FAQ (Aktualisiert am 20.10.2026)

Wie kann ich am Kurs teilnehmen?
> Komm zum entsprechenden Termin in den Discord-Kanal

Ist eine Anmeldung erforderlich?
> Nein

Findet der Kurs jede Woche statt?
> Ja, immer am gleichen Termin.
> Falls es mal ausfällt, wird das frühzeitig über Discord bekannt gegeben.

Wie lange dauert eine Kurseinheit?
> 45-60 Minuten.

Wird der Kurs aufgezeichnet?
> Ja, aber nur aktive Teilnehmer erhalten Zugriff auf die die Aufnahme.
> Außerdem ist in den anfänglichen Einheiten nur meine eigene Stimme zu hören.

Werden Mitschriften / Lösungen veröffentlicht?
> Ja.
> Allerdings sind die Mitschriften meistens inkohärente Codestücke, mit denen man ohne die mündliche Erklärung nichts anfangen kann.

Wie viele Kurseinheiten gibt es?
> Beim vorherigen Kurs waren es 21.
> Natürlich muss niemand bis zum Ende bleiben.

Gibt es Übungen?
> Ja. Ich empfehle auch stark, diese zu lösen.

Muss ich im Kurs mitarbeiten?
> Du wirst nicht gezwungen, aber trotzdem "ja".
> Wer im Kurs nur zuhört, aber nicht aktiv dabei ist, hat es deutlich schwieriger.

Muss ich absagen, wenn ich mal nicht dabei bin, oder zu spät komme?
> Nein

Gibt es am Ende des Kurses ein Zertifikat?
> Leider nein.
> Du kannst dir nach dem Kurs aber definitiv in den Lebenslauf schreiben, dass du Python programmieren kannst.
